المفهوم

التداخل (Nesting)

  • التداخل: وضع كائن أو أكثر داخل كائن آخر.
  • العبارة المتداخلة: عبارة موجودة داخل عبارة أخرى في المقطع البرمجي.
  • الجملة الشرطية المتداخلة: جملة if موجودة داخل جملة if أو if…else أخرى.
  • يمكن دمج أي عدد من العبارات داخل بعضها.
if الشرط الأول:لا ندخل هنا إلا إذا تحقق الشرط الأول
if الشرط الثاني:ولا هنا إلا إذا تحقق الشرطان معًا
العبارة
الصيغة العامة

المسافة البادئة هي الطريقة الوحيدة لفهم التداخل

nested.py
if الشرط الأول:
    عبارة 1
    if الشرط الثاني:
        عبارة 2
    else:
        عبارة 3
elif الشرط الثالث:
    عبارة 4
    if الشرط الرابع:
        عبارة 5
    else:
        عبارة 6
  • الشرط الثاني لا يُفحص إلا إذا تحقق الشرط الأول.
  • الشرط الرابع لا يُفحص إلا إذا لم يتحقق الأول وتحقق الثالث.
  • else تتبع جملة if التي تقع على نفس مستوى المسافة البادئة.

متى تُنفَّذ «عبارة 3»؟
